# 手機通知設定指南（PWA Web Push）

**實測日期：** 2026-10-16（Asia/Taipei）  
**實測裝置：** 小米／紅米 Android + Chrome（約 Chrome 155）  
**示範站：** https://pwa-push-demo.onrender.com  

本文件記錄實際測過的現象與解法，方便以後接預約系統的店家通知時直接照做，不必重踩坑。

---

## 實測結論（摘要）

| 現象 | 結果 |
|---|---|
| 第一次按「開啟通知」權限顯示 `default`（系統提示沒出現或被關掉） | 需到網站設定手動允許通知 |
| Chrome **整個關掉**、手機鎖屏 | 伺服器送達後仍可收到（不必開著網頁） |
| 鎖屏時無提示音、解鎖才看到通知 | 多半是「網站專屬」通知管道未開發聲／鎖定螢幕／懸浮 |
| 開啟網站專屬管道（發聲、鎖定螢幕、懸浮等）後 | **連續兩次**鎖屏即亮螢幕並有提示音 |
| 伺服器端 | 使用 `urgency: 'high'`、`TTL: 3600`；已確認送達 Google FCM |

**關鍵修復：** Chrome → 通知 → **網站** → `pwa-push-demo.onrender.com`（或你的正式網域）→ 打開發聲、鎖定螢幕通知、懸浮通知等。

## Android／Chrome：建議檢查順序

### 1. Chrome App 層級通知

路徑大致為：手機「設定 → 應用程式 → Chrome → 通知」。

請確認：

- [ ] **允許通知**＝開
- [ ] **懸浮通知**＝開（名稱可能因系統略有不同）
- [ ] **鎖定螢幕通知**＝開／顯示
- [ ] **發聲**＝開（實測時這裡曾是關的，會導致沒提示音）
- [ ] **震動**＝依喜好開啟

### 2. 網站專屬通知管道（最重要）

每個網站在 Chrome 裡常有**自己的一組**通知設定，和 Chrome 總開關是分開的。

常見路徑（畫面文字可能略有差異）：

1. 打開 Chrome → 右上角 ⋮ → **設定 → 通知**  
   或：從系統「Chrome → 通知」頁進入 **網站** 區塊  
2. 找到 `pwa-push-demo.onrender.com`（正式站則是你的網域）  
3. 確認該網站：
   - [ ] 允許通知
   - [ ] 發聲
   - [ ] 鎖定螢幕通知
   - [ ] 懸浮通知（Heads-up）
   - [ ] 重要性／「重要」（若有此選項）

實測：總開關都開了，但鎖屏仍靜音、解鎖才出現；**把網站專屬管道打開後**，鎖屏立刻有聲有亮。

也可在網頁網址列左側圖示 → 權限／網站設定 → 把通知改成「允許」。若權限一直是 `default`，代表系統提示沒成功彈出，必須走這條手動路徑。

### 3. 小米／紅米：背景與省電

路徑多在「設定 → 應用程式 → Chrome」或該 App 的「電量／省電」：

- [ ] **自啟動**＝開  
- [ ] **省電策略**＝**無限制**（不要用「省電」或「限制背景」）

否則 Chrome 一被系統限制，推播可能延遲到解鎖或重新打開 Chrome 才出現。

### 4. 小米／紅米：額外建議（未逐項單獨驗證）

以下在對話中曾建議，**不是每一項都單獨 A/B 驗證過**；網站專屬管道已確認是關鍵。可作補強：

- 通知出現時**長按**該則通知 → 設為「重要」，或關閉「靜音／收合」之類選項。  
- 多工畫面長按 Chrome 卡片 → **鎖定**（小鎖），避免鎖屏後被清掉。  
- 「設定 → 通知與控制中心 → 鎖定螢幕通知」選「顯示」，不要「隱藏」。

## iPhone／Safari（尚未在本專案實測）

規格上可行，但 **2026-10-16 本次未用 iPhone 實測**。依 Web Push／PWA 一般要求：

1. **iOS 16.4 以上**  
2. 用 **Safari** 打開網址  
3. 分享 → **加入主畫面**  
4. **必須從主畫面圖示打開**（在 Safari 分頁裡無法開通知）  
5. 在已加入主畫面的 App 內按「開啟通知」→ 允許  

若之後用 iPhone 測過，請把結果補進本文件「實測結論」表。

## 店家端短檢查清單（可放進產品說明）

適用：Android 店家手機要收「新預約」網頁推播。

1. 用 **Chrome** 打開後台／通知頁網址（第一次若剛喚醒伺服器，可能等約一分鐘）。  
2. 按「開啟通知」→ 系統詢問時選 **允許**。  
   - 若沒跳出、或狀態是未允許：網址列圖示 → 權限 → 通知改允許；或到 Chrome 設定 → 通知 → 網站 → 選你的網域允許。  
3. 到 **Chrome 通知 → 網站 →（你的網域）**，打開：**發聲、鎖定螢幕、懸浮／重要**。  
4. （小米／紅米）Chrome：**自啟動開**、**省電＝無限制**。  
5. 可把網頁「加到主畫面」方便之後開啟；Android 不一定要，但建議。  
6. **測試：** 鎖定手機、等店長或系統發一則測試；應亮螢幕並有提示音。  
7. 換手機或清除 Chrome 資料後，需重新允許並再訂閱一次。

備註：推播非 100% 即時（省電、系統限制可能延遲）。正式產品建議 **推播 + Email 備援**。

## 與程式的對應

- 前端訂閱：`public/index.html`（`Notification.requestPermission`、`pushManager.subscribe`、`POST /subscribe`）  
- 顯示通知：`public/sw.js`（`push` → `showNotification`）  
- 高優先級發送：`lib.js` → `web-push` 選項 `{ TTL: 3600, urgency: 'high' }`  
- 部署與環境變數：見 repo 根目錄 `README.md`  

伺服器已用高優先級時，若鎖屏仍無聲，優先查**手機端網站專屬管道**，而不是再改後端 urgency。
